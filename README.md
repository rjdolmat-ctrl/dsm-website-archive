# Digital Sound Magic website archive

Static copy of the downloaded DSM website. GitHub Pages publishes `main` from the repository root. `index.html` is the entry point; `.nojekyll` preserves static assets.

WordPress API responses and feeds are omitted. Four videos exceeding 100 MiB are omitted and replaced with archive notices; the smaller game audio demo is retained. The original local download is separate and unchanged.

This is a historical static website: WordPress server functionality is unavailable. Download filenames and references were normalized for static hosting. No custom domain is configured here.

Two missing image assets were recovered from the original website. Legacy analytics scripts and the obsolete WordPress sitemap reference were removed from this publication copy. The downloaded contact URLs already contain the homepage content; that content is preserved.
